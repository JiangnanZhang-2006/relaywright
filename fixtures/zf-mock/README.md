# 正方教务夹具

这里是**假的**正方教务「个人课表查询」页面，只给 relaywright 的测试和演示用。没有真实姓名、学号或学校数据。

- `v1/`：隐藏的原生 `<select>`、手写的 chosen 风格下拉框、非语义导航、同域 iframe、密码框。查询按钮会 `fetch` 本目录的 JSON，用来走网络空闲等待。
- 学年学期没有对应 JSON 时返回 404，页面显示「该学年学期尚无您的课表！」。
- 已放进夹具的学期：2025-2026 第 1 学期（`2025-3.json`）、2025-2026 第 2 学期（`2025-12.json`）、2026-2027 第 1 学期（`2026-3.json`）。

v2（给自愈演示用的改版页面）以后再加。
