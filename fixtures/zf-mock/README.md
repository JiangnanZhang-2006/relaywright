# 正方教务夹具

这里是**假的**正方教务「个人课表查询」页面，只给 relaywright 的测试和演示用。没有真实姓名、学号或学校数据。

- `v1/`：隐藏的原生 `<select>`、手写的 chosen 风格下拉框、非语义导航、同域 iframe、密码框。查询按钮会 `fetch` 本目录的 JSON，用来走网络空闲等待。
- `v1/portal.html`：门户页（对应 `xtgl/index_initMenu.html`）。标题是「教学管理信息服务平台」。顶栏是非语义的可点 `div`（报名申请、信息查询、教学评价）。点「信息查询」后出现两个课表入口：`#link-timetable` 用 `window.open` 打开 `index.html?gnmkdm=N2151&layout=default`，`#link-timetable-blank` 是普通的 `target="_blank"` 链接。数据仍是假的。
- 学年学期没有对应 JSON 时返回 404，页面显示「该学年学期尚无您的课表！」。
- 已放进夹具的学期：2025-2026 第 1 学期（`2025-3.json`）、2025-2026 第 2 学期（`2025-12.json`）、2026-2027 第 1 学期（`2026-3.json`）。
- `v2/`：同一套数据和通知（相对路径指向 `v1/`），但是页面已经改过。导航顺序不同，学年的标签变成「学年度」，查询按钮的文字变成「检索」、id 变成 `btn_query`（class 仍是 `btn btn-primary`）。这是留给以后自愈的「页面变了」变体；按 v1 录下来的 css id 和按钮文字都对不上。
